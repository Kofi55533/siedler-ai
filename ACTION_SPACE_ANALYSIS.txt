==============================================
ACTION PHASE FLOW
==============================================

Multi-Step Action System:
1. MAIN PHASE: Select one of 12 main actions
   - wait:         Immediate (1 step)
   - build:        Multi-phase (select location)
   - upgrade:      Multi-phase (select building)
   - research:     Multi-phase (select technology)
   - recruit:      Multi-phase (select soldier type)
   - buy_serf:     Multi-phase (select house)
   - dismiss_serf: Immediate (1 step)
   - assign_serf:  Multi-phase (select assignment)
   - demolish:     Multi-phase (select building)
   - bless:        Multi-phase (select target)
   - tax:          Multi-phase (select rate)
   - alarm:        Multi-phase (select trigger type)

2. SELECTION PHASE: Choose specific target
   - Number of choices varies by action type
   - Examples:
     * 28 possible buildings to build
     * 35 possible buildings to upgrade
     * 50 possible technologies to research

3. EXECUTION: Perform the selected action

==============================================
KEY INSIGHTS
==============================================

1. Two-Layer Action Space:
   - Layer 1: 12 main action categories (discrete choice)
   - Layer 2: Sub-action selections (variable count per category)

2. Action Masking:
   - Initial state: 8 valid main actions
   - Invalid: upgrade (3), research (3), demolish (8) - require resources/buildings

3. Resource-Driven Actions:
   - Tech (50): Research available technologies
   - Build (28): Construct buildings at player base
   - Upgrade (35): Level up existing buildings
   - Recruit (24): Train different soldier types

4. Batch Operations:
   - Tree harvesting: 36 actions
   - Wood zones: 36 actions
   - Building placement: 84 actions
   - Mine/deposit/shaft: 24 actions each

5. Game Mechanics:
   - Serf system: 6 serf houses + 6 management actions
   - Blessings: 5 shrine blessing options
   - Taxation: 5 tax rate levels
   - Alarms: 2 alert states
